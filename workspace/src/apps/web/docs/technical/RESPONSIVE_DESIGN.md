# Responsive design

**Trạng thái:** Đã duyệt · **Cập nhật:** 2026-10-18

| Vùng | Kích thước kiểm tra | Hành vi |
|---|---:|---|
| Mobile | 360–767px | Một cột, drawer, CTA toàn chiều rộng |
| Tablet | 768–1023px | Một/hai cột theo nội dung |
| Laptop | 1024–1439px | Desktop thu gọn |
| Desktop | >=1440px | Bám frame Figma 1440 |

- Search form xếp dọc trên mobile; filter mở trong drawer.
- Trip card thành danh sách một cột.
- Seat map giữ tỷ lệ và cuộn trong vùng riêng khi cần.
- Booking summary chuyển xuống dưới hoặc bottom sheet.
- Auth ẩn scenic panel ở màn hình hẹp.
- Admin navigation dùng drawer; bảng đổi sang card khi cần thao tác hoặc cuộn ngang có cột hành động ổn định.
- Dialog thành full-screen trên mobile.
- Không dựa riêng vào hover; touch target tối thiểu 44px.
- Kiểm tra bắt buộc ở 360, 768, 1024, 1440 và 1920px.
