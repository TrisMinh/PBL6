# BLUE Customer web

Independent customer application, shared design/source maintained in `../web`.

- `npm run dev`: http://localhost:5173
- `npm run build`: creates this app only in `dist/client`
- `npm run preview`: serve the production mock app

Install frontend dependencies once in `../web` with Node 24.22.0 / pnpm 10.34.7 (`pnpm install --frozen-lockfile`). Mock is default. See `../web/README.md` for accounts and scenarios.
