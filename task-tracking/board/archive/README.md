# Board Archive

Cuối mỗi sprint, lưu snapshot board thành `sprint-<nn>-closed.md` trước khi thay nội dung board hiện tại. Snapshot phải giữ committed/Done/carry-over PD, card Blocked, evidence và quyết định closeout.

Không đưa card chưa Done vào cột Done chỉ để đóng sprint; chuyển card đó sang carry-over với lý do và owner.
