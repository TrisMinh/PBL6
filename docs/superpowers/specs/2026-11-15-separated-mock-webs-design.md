Existing original FE/BE branches remain untouched; use codex/fe-be-integration with prior removal of legacy backoffice preserved.

Customer has no operator/admin routes. Staff sites have no customer booking routes. Keep canonical /operator/* and /admin/* deep links within their respective sites. Shared source may remain in web as the maintained frontend package, never a combined deployed application.

Retain Travel v3 assets, tokens, states, responsive layouts and accessibility. Complete operator navigation holes using existing design patterns. Existing quality regressions must be diagnosed rather than hidden. Run typecheck, lint, full unit suite, build/prerender, responsive browser checks and cross-app smoke. Record exact remaining limitations; no unsupported 100% claim.
