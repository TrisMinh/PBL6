# Hồ sơ tài liệu PBL6

## Bản hiện hành

- Tài liệu: `releases/PBL6-SRS-v001.docx`
- Phiên bản: PBL6 SRS v001
- Trạng thái: Hoàn thành
- Nhật ký chi tiết: `CHANGELOG.md`

## Cấu trúc thư mục

- `releases/`: các bản SRS đã đánh số phiên bản.
- `sources/`: DOCX và PDF gốc trước khi bổ sung caption, diagram và định dạng.
- `references/`: SRS 2 và tài liệu mẫu dùng để đối chiếu.

Không chỉnh sửa trực tiếp các file trong `sources` và `references`. Khi cần chỉnh bản hiện hành, sao chép thành phiên bản kế tiếp rồi làm việc trên file mới.
